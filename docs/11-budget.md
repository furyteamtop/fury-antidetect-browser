# 11 — Что стоит денег, а что нет

Короткий ответ: **разработку можно сделать почти бесплатной. Минимум — $99 в год.**
Всё остальное — либо ноль, либо железо, которое у вас, скорее всего, уже есть.

Но настоящая цена проекта — не деньги, а **время одного C++-инженера, бессрочно**.
Это то, что нельзя получить бесплатно.

## Стоит денег

| Что | Цена | Обязательно? |
|---|---|---|
| **Apple Developer Program** | **$99/год** | **Практически да.** См. ниже |
| Windows code signing (OV) | ~$200-400/год | Нет на старте |
| Windows code signing (EV) | ~$300-600/год | Нет на старте, да при росте |
| Юрлицо для сертификата | зависит от юрисдикции | Только вместе с сертификатом |
| Облачные билд-раннеры | $0-1500/мес | Нет, если есть своё железо |

### Apple Developer — почему почти обязателен

Без нотаризации macOS показывает не «предупреждение», а по сути отказ: приложение
из интернета без подписи Developer ID блокируется, и обходной путь для пользователя
стал сложнее в последних версиях системы — нужно лезть в Системные настройки →
Конфиденциальность и безопасность и явно разрешать.

Технически распространять неподписанное можно: пользователь снимает карантин вручную.

```bash
xattr -dr com.apple.quarantine /Applications/Fury.app
```

Но для антидетект-браузера это плохо вдвойне: инструкция «отключите защиту macOS
и запустите бинарник из интернета» выглядит ровно как инструкция от малвари.
Доверие к проекту вы так не построите. $99 в год — самая оправданная трата в списке.

### Windows — можно начать бесплатно

Неподписанный `.exe` **запускается**. SmartScreen покажет синее окно
«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
Некрасиво, но работает, и для раннего OSS-проекта терпимо.

Проблема появляется при регулярных релизах: OV-сертификат набирает репутацию
неделями, и **каждая новая версия проходит период недоверия заново**. Если вы
выпускаете релиз раз в месяц ([03](03-chromium-fork.md)), OV не успевает
«прогреться». Поэтому: старт без подписи → при живом потоке пользователей сразу EV,
минуя OV.

## Железо для сборки — главный практический вопрос

Chromium нельзя собрать в бесплатном облаке. Free-раннер GitHub Actions даёт
4 vCPU / 16 ГБ RAM / ~14 ГБ свободного диска, а только `gclient sync` требует ~100 ГБ.

**Бесплатный путь: self-hosted runner на своём железе.** GitHub позволяет подключить
свою машину как раннер бесплатно, включая публичные репозитории.

Что нужно:

| Платформа | Требования | Реальность |
|---|---|---|
| macOS arm64 | Mac на Apple Silicon, 16+ ГБ RAM, **250 ГБ свободного диска** | Ваш рабочий Mac подойдёт, если хватает диска |
| macOS x64 | Тот же Mac (кросс-компиляция arm64→x64 работает) | Не нужна отдельная машина |
| Windows x64 | Windows-машина, 16+ ГБ RAM, 250 ГБ диска, 8+ ядер | Игровой ПК подойдёт |

Кросс-компиляции под macOS с Linux **не существует** — нужен физический Mac.
Windows собирать с Linux формально можно, но на практике сложно и хрупко;
проще иметь Windows-машину.

Время сборки на слабом железе: 4-8 часов вместо 1.5-3. Терпимо, если это
раз в месяц и по ночам. Инкрементальные сборки после правки патча — 5-30 минут.

**Внешние диски не подойдут** — сборка упирается в IOPS. Нужен внутренний SSD.

## Три сценария бюджета

### Сценарий «ноль»: $99/год

- Сборка на своём Mac и своём Windows-ПК
- Windows-релизы без подписи, SmartScreen терпим
- macOS подписан и нотаризован
- Раздача через GitHub Releases
- Сервер каждый пользователь поднимает себе сам (docker-compose)
- Демо-сервера у вас нет

Работает. Именно так живут большинство OSS-браузерных форков.

### Сценарий «удобный»: ~$600-800/год

Добавляется:
- EV-сертификат Windows (~$400/год)
- Домен + лендинг (~$20/год)
- VPS под демо-сервер и статус-страницу прогонов detect-suite (~$10-20/мес)

### Сценарий «команда работает быстро»: $500-2000/мес

Добавляется выделенная билд-ферма в облаке, чтобы сборка занимала час, а не ночь,
и чтобы CI гонял detect-suite на каждый PR. Нужно только когда контрибьюторов
станет много.

## Что действительно дорого

Деньги здесь — не главный ресурс. Главное:

**Один человек, который знает C++ и Chromium, занятый бессрочно.** Ребейз каждые
4 недели никуда не денется. Если этот человек — вы, и вы делаете это в свободное
время, проект бесплатный по деньгам, но стоит вам ~1 недели в месяц навсегда.
Если такого человека нет — никакой бюджет из этого списка проблему не решит.

Честный вывод: **$99/год — это правда. Но 4-6 месяцев работы до первого релиза
и неделя в месяц после — тоже правда, и она дороже.**
