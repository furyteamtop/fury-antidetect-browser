Не верьте — замерьте

Проект держится на том, что ни одно утверждение здесь не просит верить на слово.

  • Стенд в комплекте. tools/detect-suite снимает ~460 значений отпечатка в девяти контекстах исполнения — главный фрейм, воркеры, ворклет, четыре вида iframe, включая кросс-доменный в своём процессе.
  • Гейт. fury-detect gate проверяет отпечаток на внутренние противоречия и возвращает ненулевой код — его можно поставить в CI.
  • Отчёт в каждом релизе. REPORT.md называет sha256 ядра, серию патчей и коммит, из которого всё собрано.
  • Сравнение рядом. status.html — последний замер: Fury и настоящий Chrome на одной машине, поле к полю.

Почему бесплатно

Ни мест, ни оплаты за профиль, ни припрятанного платного тарифа, ни телеметрии. Это решение, а не этап: лицензия AGPL, и все замеры опубликованы именно затем, чтобы никому не приходилось верить на слово.

За проектом не стоит компания, и продавать тут нечего. Расходы скучные: сертификат подписи, чтобы скачанная сборка не воевала с Gatekeeper, и машина, чтобы пересобирать ядро под каждый выпуск Chromium.

Three things together

Each exists somewhere on its own. Together, nowhere else.

A core you can build

{{PATCHES}} patches against Chromium {{CHROMIUM}}, in the repository as text. The spoofing is in C++ rather than injected JavaScript: an injection is visible from the page, a patch is not.

A team, not a shared folder

Projects, roles, a permission on every action, a distributed lock and an audit trail. Access is revoked in one click — a file you handed over cannot be taken back.

A server you run yourself

One binary and Postgres on any VPS. Bundles are encrypted on your own machine, so the server holds what it cannot itself read.

The core's version is a fingerprint too

A browser three majors behind Chrome is identified by one number, before any spoofing is looked at. Ours is read out of the repository when this page is built; the others are what we measured ourselves on {{MEASURED_EN}} (the market review).

Do not take it on trust — measure it

Nothing claimed here asks to be believed.

  • The bench ships with it. tools/detect-suite dumps ~460 fingerprint values across nine execution contexts — main frame, workers, a worklet and four kinds of iframe, including a cross-origin one in its own process.
  • The gate. fury-detect gate checks a fingerprint for internal contradictions and exits non-zero, so it drops straight into CI.
  • A report in every release. REPORT.md names the core's sha256, the patch series and the commit it was all built from.
  • Side by side. status.html is the last measurement: Fury and real Chrome on the same machine, field by field.

Why it is free

No seats, no per-profile pricing, no paid tier held back, no telemetry. That is a decision rather than a stage: the licence is AGPL and every measurement is published precisely so nobody has to take anyone's word for it.

There is no company behind this and nothing is sold. What it costs is ordinary and dull — a code-signing certificate so the download does not fight Gatekeeper, and a machine to rebuild the core against every Chromium release.
